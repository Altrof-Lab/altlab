# GitHub & MCP Rules

- **Project name in short:** AL-CORE
- **Language:** All GitHub artifacts (Issues, PRs, Commit messages) MUST be in **English**. But in comment of issue or PR can be in Russian language for explanation in detail.
- **Issue Title Format:** `[project_name_in_short]: Brief summary in English` (e.g., `[AL-CORE]: Add AI into project`).
- **Issue Body:** Include Problem Description, Proposed Solution, and Acceptance Criteria.
- **Branch Naming:** `[issue-number]-[description]` (e.g., `2-implement-ai` or `al-core-2-implement-ai`).
- **Documentation Self-Update:** Propose edits to `.agents/*.md` via Diff when introducing major architectural changes.
- **Issue Project:** Should be linked with `Altrof Dev Dashboard`
